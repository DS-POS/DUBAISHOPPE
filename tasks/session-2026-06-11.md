## Bug 4 — Billing screen added GST on top of incl-GST selling_price

**File:** `lib/gst.ts`

**Problem:** `selling_price` is stored as incl-GST (₹6500).
Billing screen was treating it as ex-GST and adding 18% on top → ₹7670 (wrong).

**The rule:** `selling_price` = what customer pays total (incl. all GST). Always.

**Fix:** Changed `calculateLineGST` to back-calculate taxable from incl-GST price:

```
// Before (WRONG): adds GST on top
taxable_amount = rate × qty
total = taxable_amount + (taxable_amount × gst_rate/100)

// After (CORRECT): back-calculates from incl-GST
total = rate × qty               // incl-GST
taxable_amount = total / (1 + gst_rate/100)
gst_amount = total - taxable_amount
```

Example: ₹6500 @ 18% GST
- taxable = ₹6500 / 1.18 = ₹5508.47
- GST = ₹991.53
- total = ₹6500 ✓ (not ₹7670)

## Bug 5 — Re-importing invoice never updated existing product's selling_price or gst_rate

**File:** `actions/import-invoice.ts`

**Problem:** The `use_existing` branch had a `continue` that skipped the product update block entirely.
So re-importing the same invoice never updated `selling_price`, `cost_price`, or `gst_rate`.
Product stayed with whatever values it was created with originally.

**Also:** `gst_rate` was never included in the update — so products always kept their original GST rate (18%) even if the invoice showed 12%.

**Fix:** Moved product update INTO the `use_existing` branch before `continue`, and added `gst_rate` to the update:

```typescript
// Before (BROKEN):
if (item.action === 'use_existing') {
  productIdMap.set(i, item.product_id)
  continue  // ← skipped everything below!
}
// this block was unreachable for use_existing:
if (item.action === 'use_existing' && item.selling_price != null) {
  await supabase.from('products').update({ selling_price, cost_price })
}

// After (FIXED):
if (item.action === 'use_existing') {
  productIdMap.set(i, item.product_id)
  await supabase.from('products').update({
    cost_price: item.unit_price,
    selling_price: item.selling_price,
    gst_rate: item.new_product_gst_rate,  // ← also update GST rate
  })
  continue
}
```

## Architecture Reminder

| Field | What it means | Where |
|---|---|---|
| `cost_price` | What supplier charged incl. GST (what we paid per unit) | products, stock_in |
| `selling_price` | What customer pays incl. GST (our selling price) | products |
| `gst_rate` | Total GST % on this product (e.g. 12, 18) | products |
| `total_amount` on supplier_invoices | Grand total payable to supplier (incl. all taxes) | supplier_invoices |

**GST math at billing time:**
- `taxable = selling_price / (1 + gst_rate/100)`
- `gst = selling_price - taxable`
- `total = selling_price` (stays same, GST is included)
