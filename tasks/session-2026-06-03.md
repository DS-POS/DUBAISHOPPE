## How It Works
1. `/stock-in` shows all supplier invoices with red/yellow/green payment badges
2. "↑ Import Invoice" → `/stock-in/import`
3. Upload PDF/image → Claude Vision extracts all line items
4. Review: each item = "Link Existing Product" OR "Create New Product" OR "Skip"
5. Confirm → products created (SKU: `IMP-XXXXXX`), stock_in rows inserted, `supplier_invoices` row created
6. Redirect to `/stock-in/[id]` — shows items + payment history
7. "+ Add Payment" → enter custom amount, method, reference → status auto-recomputes

## Payment Status Logic
```
totalPaid = sum(supplier_payments.amount)
status = totalPaid <= 0 ? 'pending' : totalPaid >= total_amount ? 'paid' : 'partial'
```
